# Rider Embedding Data Usage Guide

This guide explains how to use the data generated by the race type correlation pipeline for downstream applications, including rider type analysis and global performance prediction models.

## Overview

The race type correlation pipeline generates two primary types of data outputs:
1. **Race-type-specific rider embeddings** - Optimized correlation datasets for each race type
2. **Analysis results and metadata** - Feature selection results, cluster analysis, and model recommendations

## Data Structure Overview

## 1. Race-Type-Specific Rider Embeddings

### File Format: `{race_type}_optimized.parquet/.csv`

These files contain the final rider embeddings for each race type, with only the selected optimal features.

#### Schema
```python
{
    'rider_result_id': int,           # Primary key linking to rider_results table
    'n_races': int,                   # Number of historical races used
    'corr_feature_1': float,          # Correlation with selected feature 1
    'corr_feature_2': float,          # Correlation with selected feature 2
    # ... additional correlation features
}
```

#### Example Usage

```python
import pandas as pd

# Load GC rider embeddings
gc_embeddings = pd.read_parquet('race_type_optimized_data/gc_optimized.parquet')

# View structure
print(f"Shape: {gc_embeddings.shape}")
print(f"Columns: {gc_embeddings.columns.tolist()}")
print(f"Riders: {gc_embeddings['rider_result_id'].nunique()}")

# Example record
print(gc_embeddings.head(1))
# Output:
#   rider_result_id  n_races  corr_variance_normalized  corr_gini_coefficient  ...
# 0          174479       12                    -0.883                  0.767  ...
```

## 3. Usage Patterns

### For Rider Type Analysis

```python
import pandas as pd
import json

# 1. Load embeddings for specific race type
gc_embeddings = pd.read_parquet('race_type_optimized_data/gc_optimized.parquet')

# 2. Load cluster information
with open('race_type_analysis/gc_analysis_results.json', 'r') as f:
    gc_analysis = json.load(f)

# 3. Get cluster characteristics
cluster_chars = gc_analysis['clustering_analysis']['cluster_characteristics']
optimal_percentile = gc_analysis['recommendations']['summary']['recommended_percentile']
clusters = cluster_chars[optimal_percentile]['cluster_characteristics']

# 4. Analyze rider types
for cluster_id, cluster_info in clusters.items():
    print(f"Cluster {cluster_id}: {cluster_info['size']} riders")
    for feature in cluster_info['top_features'][:3]:
        print(f"  - {feature['feature']}: {feature['mean_correlation']:.3f}")

# 5. Join with rider metadata from database
# (Connect embeddings to rider_results table using rider_result_id)
```

### For Global Performance Prediction

```python
import pandas as pd
import sqlite3

# 1. Load optimized embeddings for desired race type
race_type = 'all'  # or 'gc', 'stage', etc.
embeddings = pd.read_parquet(f'race_type_optimized_data/{race_type}_optimized.parquet')

# 2. Join with rider_results table to get target variables and metadata
with sqlite3.connect('database/database/cycling_races.db') as conn:
    rider_results = pd.read_sql("""
        SELECT 
            rr.id as rider_result_id,
            rr.rider_id,
            rr.competition_id,
            rr.place,
            rr.uci_points_proportional,
            rr.uci_points_actual,
            c.date as competition_date,
            c.competition_type,
            r.category as race_level
        FROM rider_results rr
        JOIN competitions c ON rr.competition_id = c.id
        JOIN races r ON c.race_id = r.id
    """, conn)

# 3. Merge embeddings with rider results
model_data = embeddings.merge(rider_results, on='rider_result_id', how='inner')

# 4. Add race features for the target competition
race_features = pd.read_sql(f"""
    SELECT competition_id, variance_normalized, gini_coefficient, total_finishers
    FROM race_features_90  -- Use same percentile as embeddings
""", conn)

model_data = model_data.merge(race_features, on='competition_id', how='inner')

# 5. Create feature matrix for ML
feature_cols = [col for col in model_data.columns if col.startswith('corr_')]
race_feature_cols = ['variance_normalized', 'gini_coefficient', 'total_finishers']
metadata_cols = ['n_races', 'race_level']

X = model_data[feature_cols + race_feature_cols + metadata_cols]
y = model_data['uci_points_proportional']  # or other target variable

print(f"Model data shape: {X.shape}")
print(f"Features: {len(feature_cols)} correlations + {len(race_feature_cols)} race features + {len(metadata_cols)} metadata")
```

## 4. Data Quality Considerations

### Embedding Quality Indicators

1. **Number of races (`n_races`)**: Higher is better, indicates more stable correlations
2. **Feature count**: Varies by race type, typically 15-25 features
3. **Cluster quality**: Check silhouette scores in analysis results

### Recommended Filtering

```python
# Filter for high-quality embeddings
min_races_threshold = {
    'gc': 10,
    'stage': 20, 
    'one_day': 12,
    'stage_one_day': 15,
    'all': 30
}

# Filter embeddings
quality_embeddings = embeddings[
    embeddings['n_races'] >= min_races_threshold[race_type]
]
```

### Missing Data Handling

```python
# Check for missing correlations
correlation_cols = [col for col in embeddings.columns if col.startswith('corr_')]
missing_summary = embeddings[correlation_cols].isnull().sum()

# Handle missing correlations (rare but possible)
embeddings[correlation_cols] = embeddings[correlation_cols].fillna(0.0)
```

## 5. Integration Patterns

### Pattern 1: Single Race Type Analysis

```python
def load_race_type_embedding(race_type: str) -> pd.DataFrame:
    """Load optimized embedding for a specific race type."""
    embedding_file = f'race_type_optimized_data/{race_type}_optimized.parquet'
    config_file = f'race_type_optimized_data/{race_type}_config.json'
    
    embedding_data = pd.read_parquet(embedding_file)
    
    with open(config_file, 'r') as f:
        config = json.load(f)
    
    return embedding_data, config

# Usage
gc_data, gc_config = load_race_type_embedding('gc')
print(f"Loaded {len(gc_data)} riders with {gc_config['feature_count']} features")
```

### Pattern 2: Multi-Race Type Comparison

```python
def load_all_embeddings() -> dict:
    """Load embeddings for all race types."""
    race_types = ['gc', 'stage', 'one_day', 'stage_one_day', 'all']
    embeddings = {}
    
    for race_type in race_types:
        try:
            data, config = load_race_type_embedding(race_type)
            embeddings[race_type] = {'data': data, 'config': config}
        except FileNotFoundError:
            print(f"No data found for {race_type}")
    
    return embeddings

# Usage
all_embeddings = load_all_embeddings()
for race_type, embedding_info in all_embeddings.items():
    data = embedding_info['data']
    config = embedding_info['config']
    print(f"{race_type}: {len(data)} riders, {config['feature_count']} features")
```

### Pattern 3: Global Model Preparation

```python
def prepare_global_model_data(
    race_type: str, 
    target_column: str = 'uci_points_proportional',
    include_race_features: bool = True
) -> tuple:
    """Prepare data for global performance prediction model."""
    
    # Load embedding
    embeddings, config = load_race_type_embedding(race_type)
    percentile = config['percentile']
    
    # Join with rider results and race features
    with sqlite3.connect('database/database/cycling_races.db') as conn:
        query = f"""
        SELECT 
            rr.id as rider_result_id,
            rr.{target_column},
            rr.place,
            c.competition_type,
            r.category as race_level,
            rf.*
        FROM rider_results rr
        JOIN competitions c ON rr.competition_id = c.id
        JOIN races r ON c.race_id = r.id
        {'JOIN ' + percentile + ' rf ON c.id = rf.competition_id' if include_race_features else ''}
        WHERE rr.id IN ({','.join(map(str, embeddings['rider_result_id']))})
        """
        
        context_data = pd.read_sql(query, conn)
    
    # Merge
    model_data = embeddings.merge(context_data, on='rider_result_id')
    
    # Separate features and target
    feature_cols = [col for col in model_data.columns 
                   if col.startswith('corr_') or col in ['n_races', 'variance_normalized', 'total_finishers']]
    
    X = model_data[feature_cols]
    y = model_data[target_column]
    
    return X, y, model_data

# Usage
X, y, full_data = prepare_global_model_data('gc', target_column='uci_points_proportional')
print(f"Prepared data: {X.shape[0]} samples, {X.shape[1]} features")
```

## 6. Performance Optimization Tips

1. **Use Parquet format** for faster loading of large datasets
2. **Filter early** by `n_races` to ensure data quality
3. **Cache embeddings** if using repeatedly in analysis
4. **Use appropriate race type** for your analysis scope
5. **Check correlation counts** - some features may be sparse

## 7. Troubleshooting

### Common Issues

1. **Empty embeddings**: Check if riders meet minimum race thresholds
2. **Missing features**: Verify percentile table exists in database
3. **Low cluster quality**: Consider different race type or feature selection
4. **Memory issues**: Use CSV format for very large datasets

### Data Validation

```python
def validate_embedding_data(race_type: str):
    """Validate embedding data quality."""
```
