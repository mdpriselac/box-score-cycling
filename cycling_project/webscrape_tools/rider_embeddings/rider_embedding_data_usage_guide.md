# Rider Embedding Data Usage Guide

This guide explains how to use the data generated by the race type correlation pipeline for downstream applications, including rider type analysis and global performance prediction models.

## Overview

The race type correlation pipeline generates three primary types of data outputs:
1. **Race-type-specific rider embeddings (OPTIMIZED)** - Feature-selected correlation datasets for each race type
2. **Race-type-specific rider embeddings (FULL)** - Complete correlation datasets with all features for baseline comparison
3. **Analysis results and metadata** - Feature selection results, cluster analysis, and model recommendations

## Data Structure Overview

## 1. Race-Type-Specific Rider Embeddings

The pipeline generates two types of rider embeddings for comparison and different use cases:

### A. OPTIMIZED Embeddings (race_type_optimized_data/)

#### File Format: `{race_type}_optimized.parquet/.csv`

These files contain the final rider embeddings for each race type, with only the selected optimal features (typically 5-7 features).

#### Schema
```python
{
    'rider_result_id': int,           # Primary key linking to rider_results table
    'n_races': int,                   # Number of historical races used
    'corr_feature_1': float,          # Correlation with selected feature 1
    'corr_feature_2': float,          # Correlation with selected feature 2
    # ... additional correlation features
}
```

#### Example Usage - Optimized Embeddings

```python
import pandas as pd

# Load GC rider embeddings (optimized)
gc_embeddings = pd.read_parquet('race_type_optimized_data/gc_optimized.parquet')

# View structure
print(f"Shape: {gc_embeddings.shape}")
print(f"Columns: {gc_embeddings.columns.tolist()}")
print(f"Riders: {gc_embeddings['rider_result_id'].nunique()}")

# Example record
print(gc_embeddings.head(1))
# Output:
#   rider_result_id  n_races  corr_variance_normalized  corr_gini_coefficient  ...
# 0          174479       12                    -0.883                  0.767  ...
```

### B. FULL Embeddings (race_type_full_embeddings/)

#### File Format: `{race_type}/{percentile}_full.parquet`

These files contain COMPLETE rider embeddings with ALL features (typically ~37 features) for each percentile. Used for baseline comparison against optimized versions.

#### Schema
```python
{
    'rider_result_id': int,           # Primary key linking to rider_results table
    'n_races': int,                   # Number of historical races used
    'calculation_date': str,          # When correlations were calculated
    # ALL race features as correlation columns:
    'variance_normalized': float,     # Correlation with variance_normalized
    'gini_coefficient': float,        # Correlation with gini_coefficient  
    'total_finishers': float,         # Correlation with total_finishers
    'winning_time': float,            # Correlation with winning_time
    'abandon_ratio': float,           # Correlation with abandon_ratio
    # ... (~37 total features, varies by percentile)
}
```

#### Directory Structure
```
race_type_full_embeddings/
├── gc/
│   ├── race_features_30_full.parquet  # 37 features from 30th percentile
│   ├── race_features_40_full.parquet  # 37 features from 40th percentile
│   ├── ...                           # All percentiles 30-100
│   ├── race_features_100_full.parquet # 37 features from 100th percentile
│   └── gc_config.json                # Metadata for all percentiles
└── [stage, one_day, stage_one_day, all]/  # Same structure for each race type
```

### Pattern A: Optimized vs Full Embeddings Comparison

```python
import pandas as pd
import json
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error

def compare_optimized_vs_full_embeddings(race_type='gc', percentile='race_features_90'):
    """Compare performance of optimized vs full embeddings."""
    
    # Load optimized embeddings
    optimized = pd.read_parquet(f'race_type_optimized_data/{race_type}_optimized.parquet')
    
    # Load corresponding full embeddings  
    full = pd.read_parquet(f'race_type_full_embeddings/{race_type}/{percentile}_full.parquet')
    
    # Get target variable (example: next race performance)
    # This would typically come from joining with future race results
    # For demo, we'll use a synthetic target
    
    # Prepare feature matrices
    opt_features = [col for col in optimized.columns if col.startswith('corr_')]
    full_features = [col for col in full.columns if col not in ['rider_result_id', 'n_races', 'calculation_date']]
    
    # Align datasets on rider_result_id
    common_riders = set(optimized['rider_result_id']) & set(full['rider_result_id'])
    opt_aligned = optimized[optimized['rider_result_id'].isin(common_riders)].sort_values('rider_result_id')
    full_aligned = full[full['rider_result_id'].isin(common_riders)].sort_values('rider_result_id')
    
    print(f"Comparison for {race_type} - {percentile}")
    print(f"Common riders: {len(common_riders)}")
    print(f"Optimized features: {len(opt_features)}")
    print(f"Full features: {len(full_features)}")
    print(f"Feature reduction: {len(opt_features)/len(full_features):.1%}")
    
    return {
        'optimized_data': opt_aligned[opt_features],
        'full_data': full_aligned[full_features],
        'rider_ids': full_aligned['rider_result_id'],
        'n_riders': len(common_riders),
        'feature_reduction': len(opt_features)/len(full_features)
    }

# Usage
comparison = compare_optimized_vs_full_embeddings('gc', 'race_features_90')
```

### Pattern C: Full Embeddings Baseline Analysis

```python
import pandas as pd
import numpy as np

def analyze_full_embeddings_by_percentile(race_type='gc'):
    """Analyze how embeddings change across percentiles."""
    
    percentiles = ['race_features_30', 'race_features_40', 'race_features_50', 
                  'race_features_60', 'race_features_70', 'race_features_80',
                  'race_features_90', 'race_features_100']
    
    results = {}
    
    for percentile in percentiles:
        try:
            # Load full embeddings for this percentile
            df = pd.read_parquet(f'race_type_full_embeddings/{race_type}/{percentile}_full.parquet')
            
            # Calculate embedding statistics
            feature_cols = [col for col in df.columns if col not in ['rider_result_id', 'n_races', 'calculation_date']]
            
            # Calculate correlation strength and variance
            corr_matrix = df[feature_cols].corr().abs()
            np.fill_diagonal(corr_matrix.values, 0)  # Remove self-correlations
            
            results[percentile] = {
                'n_riders': len(df),
                'n_features': len(feature_cols),
                'mean_correlation_strength': df[feature_cols].abs().mean().mean(),
                'feature_redundancy': corr_matrix.mean().mean(),
                'missing_rate': df[feature_cols].isnull().mean().mean()
            }
            
        except FileNotFoundError:
            print(f"No data found for {race_type} - {percentile}")
    
    # Convert to DataFrame for easy analysis
    analysis_df = pd.DataFrame(results).T
    analysis_df.index.name = 'percentile'
    
    print(f"Full Embeddings Analysis - {race_type}")
    print(analysis_df.round(3))
    
    return analysis_df

# Usage - compare all percentiles
gc_analysis = analyze_full_embeddings_by_percentile('gc')
```

### Pattern D: Global Performance Prediction with Full vs Optimized

```python
import pandas as pd
import sqlite3

def prepare_model_data(race_type='all', use_full_embeddings=False, percentile='race_features_90'):
    """Prepare data for global performance prediction - optimized vs full embeddings."""
    
    if use_full_embeddings:
        # Load full embeddings with all features
        embeddings = pd.read_parquet(f'race_type_full_embeddings/{race_type}/{percentile}_full.parquet')
        feature_cols = [col for col in embeddings.columns if col not in ['rider_result_id', 'n_races', 'calculation_date']]
        print(f"Using FULL embeddings: {len(feature_cols)} features")
    else:
        # Load optimized embeddings with selected features
        embeddings = pd.read_parquet(f'race_type_optimized_data/{race_type}_optimized.parquet')
        feature_cols = [col for col in embeddings.columns if col.startswith('corr_')]
        print(f"Using OPTIMIZED embeddings: {len(feature_cols)} features")

    # Join with rider_results table to get target variables and metadata
    with sqlite3.connect('database/database/cycling_races.db') as conn:
        rider_results = pd.read_sql("""
            SELECT 
                rr.id as rider_result_id,
                rr.rider_id,
                rr.competition_id,
                rr.place,
                rr.uci_points_proportional,
                rr.uci_points_actual,
                c.date as competition_date,
                c.competition_type,
                r.category as race_level
            FROM rider_results rr
            JOIN competitions c ON rr.competition_id = c.id
            JOIN races r ON c.race_id = r.id
        """, conn)

        # Add race features for the target competition (use same percentile as embeddings)
        race_features = pd.read_sql(f"""
            SELECT competition_id, variance_normalized, gini_coefficient, total_finishers
            FROM {percentile}
        """, conn)

    # Merge all data
    model_data = embeddings.merge(rider_results, on='rider_result_id', how='inner')
    model_data = model_data.merge(race_features, on='competition_id', how='inner')

    # Create feature matrix for ML
    race_feature_cols = ['variance_normalized', 'gini_coefficient', 'total_finishers']
    metadata_cols = ['n_races', 'race_level'] if 'race_level' in model_data.columns else ['n_races']

    X = model_data[feature_cols + race_feature_cols + metadata_cols]
    y = model_data['uci_points_proportional']  # or other target variable

    print(f"Model data shape: {X.shape}")
    print(f"Features: {len(feature_cols)} correlations + {len(race_feature_cols)} race + {len(metadata_cols)} metadata")
    
    return X, y, model_data

# Usage - compare optimized vs full embeddings
print("=== OPTIMIZED EMBEDDINGS ===")
X_opt, y_opt, data_opt = prepare_model_data('gc', use_full_embeddings=False)

print("\n=== FULL EMBEDDINGS ===")  
X_full, y_full, data_full = prepare_model_data('gc', use_full_embeddings=True, percentile='race_features_90')

print(f"\nFeature reduction: {X_opt.shape[1]/X_full.shape[1]:.1%}")
```

## 4. Data Quality Considerations

### Embedding Quality Indicators

#### For Optimized Embeddings
1. **Number of races (`n_races`)**: Higher is better, indicates more stable correlations
2. **Feature count**: Varies by race type, typically 5-7 optimized features
3. **Cluster quality**: Check silhouette scores in analysis results

#### For Full Embeddings  
1. **Number of races (`n_races`)**: Same importance as optimized
2. **Feature count**: Consistent ~37 features across all percentiles
3. **Feature coverage**: How many features have valid correlations per rider
4. **Missing correlation rate**: Should be low (<10%) for quality embeddings

### Recommended Filtering

```python
# Filter for high-quality embeddings
```

### Pattern 3: Global Model Preparation

```python
def prepare_global_model_data(
    race_type: str, 
    target_column: str = 'uci_points_proportional',
    include_race_features: bool = True
) -> tuple:
    """Prepare data for global performance prediction model."""
    
    # Load embedding
    embeddings, config = load_race_type_embedding(race_type)
    percentile = config['percentile']
    
    # Join with rider results and race features
    with sqlite3.connect('database/database/cycling_races.db') as conn:
        query = f"""
        SELECT 
            rr.id as rider_result_id,
            rr.{target_column},
            rr.place,
            c.competition_type,
            r.category as race_level,
            rf.*
        FROM rider_results rr
        JOIN competitions c ON rr.competition_id = c.id
        JOIN races r ON c.race_id = r.id
        {'JOIN ' + percentile + ' rf ON c.id = rf.competition_id' if include_race_features else ''}
        WHERE rr.id IN ({','.join(map(str, embeddings['rider_result_id']))})
        """
        
        context_data = pd.read_sql(query, conn)
    
    # Merge
    model_data = embeddings.merge(context_data, on='rider_result_id')
    
    # Separate features and target
    feature_cols = [col for col in model_data.columns 
                   if col.startswith('corr_') or col in ['n_races', 'variance_normalized', 'total_finishers']]
    
    X = model_data[feature_cols]
    y = model_data[target_column]
    
    return X, y, model_data

# Usage
X, y, full_data = prepare_global_model_data('gc', target_column='uci_points_proportional')
print(f"Prepared data: {X.shape[0]} samples, {X.shape[1]} features")
```

## 6. Performance Optimization Tips

1. **Use Parquet format** for faster loading of large datasets
2. **Filter early** by `n_races` to ensure data quality
3. **Cache embeddings** if using repeatedly in analysis
4. **Use appropriate race type** for your analysis scope
5. **Check correlation counts** - some features may be sparse

## 7. Troubleshooting

### Common Issues

1. **Empty embeddings**: Check if riders meet minimum race thresholds
2. **Missing features**: Verify percentile table exists in database
3. **Low cluster quality**: Consider different race type or feature selection
4. **Memory issues**: Use CSV format for very large datasets
